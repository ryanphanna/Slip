# Features Roadmap

This sub-roadmap tracks new features and capabilities for Slip users.

## Active & Planned Initiatives

- **Monthly Summaries**: Automated SMS digests at month-end containing total spend, category breakdowns, and largest purchase.
- **Budget Alerts**: Monthly caps per category with automated SMS warnings when approaching limits.
- **Web Viewer**: A minimal dashboard to browse, search, and manage receipts without local terminal scripting.
- **Export**: CSV and JSON export tools for spreadsheet integration or tax reporting.
- **FinanceSocial Integration**: Pipe parsed receipts directly into FinanceSocial.
- **Email Receipt Ingestion**: Ingest email receipts (from Amazon, Uber, etc.) via dedicated email forwarding and Gemini HTML/PDF extraction.
- **Cross-Receipt Product Searching**: Natural language query tools allowing users to search specific line-item contents, compare product prices historically (e.g., *"How much was that cheese I bought last week?"* or *"Compare avocado prices from Costco vs Walmart"*).
