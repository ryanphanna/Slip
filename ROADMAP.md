# Roadmap

Slip is a personal finance backend for capturing receipt data at the point of purchase via MMS. This roadmap tracks the path from a single-user logging tool to a broader personal finance data layer.

### Product & Platform
- **[Features](docs/roadmap/FEATURES.md)**: Digests, budget alerts, web view, and email ingestion.
- **[Product](docs/roadmap/PRODUCT.md)**: Improving accuracy, stitching multi-image receipts, and custom parsing rules.
- **[Technical](docs/roadmap/TECHNICAL.md)**: Hardening functions, multi-tenancy, CI/CD pipelines, and database backups.
